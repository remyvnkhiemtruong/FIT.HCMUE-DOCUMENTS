# Ôn tập kiến thức nền tảng THPT {#🎒-on-tap-kien-thuc-nen-tang-thpt}

Ôn lại các công thức lượng giác, lũy thừa, logarit và đạo hàm cơ bản ở bậc phổ thông.

---

## 1. Công thức lượng giác bắt buộc nhớ {#_1-cong-thuc-luong-giac-bat-buoc-nho}

### 1.1. Hệ thức cơ bản
$$\sin^2 x + \cos^2 x = 1$$
$$1 + \tan^2 x = \frac{1}{\cos^2 x}, \quad 1 + \cot^2 x = \frac{1}{\sin^2 x}$$

### 1.2. Công thức cộng và nhân đôi {#_1-2-cong-thuc-cong-nhan-đoi}
$$\sin(a \pm b) = \sin a \cos b \pm \cos a \sin b$$
$$\cos(a \pm b) = \cos a \cos b \mp \sin a \sin b$$
$$\sin 2x = 2 \sin x \cos x$$
$$\cos 2x = \cos^2 x - \sin^2 x = 2\cos^2 x - 1 = 1 - 2\sin^2 x$$

### 1.3. Công thức hạ bậc {#_1-3-cong-thuc-ha-bac-rat-hay-dung-khi-tinh-tich-phan}
$$\sin^2 x = \frac{1 - \cos 2x}{2}$$
$$\cos^2 x = \frac{1 + \cos 2x}{2}$$
$$\sin^3 x = \frac{3\sin x - \sin 3x}{4}, \quad \cos^3 x = \frac{3\cos x + \cos 3x}{4}$$

---

## 2. Công thức lũy thừa và logarit {#_2-cong-thuc-luy-thua-logarit}

### 2.1. Lũy thừa
$$a^0 = 1 \quad (a \neq 0)$$
$$a^{-n} = \frac{1}{a^n}$$
$$a^{\frac{m}{n}} = \sqrt[n]{a^m}$$
$$a^x \cdot a^y = a^{x+y}, \quad \frac{a^x}{a^y} = a^{x-y}, \quad (a^x)^y = a^{xy}$$

### 2.2. Logarit ($a > 0, a \neq 1$)
$$\ln(xy) = \ln x + \ln y$$
$$\ln\left(\frac{x}{y}\right) = \ln x - \ln y$$
$$\ln(x^\alpha) = \alpha \ln x$$
$$\log_a b = \frac{\ln b}{\ln a}$$
$$a^{\log_a b} = b, \quad e^{\ln x} = x$$

---

## 3. Bảng nguyên hàm cơ bản {#_3-bang-nguyen-ham-co-ban}

| Hàm số $f(x)$ | Nguyên hàm $\int f(x) \, dx$ |
| :--- | :--- |
| $x^\alpha \; (\alpha \neq -1)$ | $\frac{x^{\alpha+1}}{\alpha+1} + C$ |
| $\frac{1}{x}$ | $\ln|x| + C$ |
| $e^x$ | $e^x + C$ |
| $a^x$ | $\frac{a^x}{\ln a} + C$ |
| $\cos x$ | $\sin x + C$ |
| $\sin x$ | $-\cos x + C$ |
| $\frac{1}{\cos^2 x}$ | $\tan x + C$ |
| $\frac{1}{\sin^2 x}$ | $-\cot x + C$ |
| $\frac{1}{1 + x^2}$ | $\arctan x + C$ |
| $\frac{1}{\sqrt{1 - x^2}}$ | $\arcsin x + C$ |
